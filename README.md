# ZPlace Timelapse

Système de génération d'images de **[ZPlace du ZEvent](https://place.zevent.fr/)** par **GuiguiBlocCraft**. Le code présenté a été refactorisé et documenté pour une meilleure compréhension.

J'ai développé ça pour générer toutes les images produites par le ZPlace, pour ainsi générer une vidéo timelapse.

Le système capture chaque image toutes les minutes.
